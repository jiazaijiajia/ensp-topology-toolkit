# 示例来源

- 输入文件：本机 eNSP V1.3.00.100 自带的 `G:\ensp\eNSP\examples\2-1Single-Area OSPF\2-1Single-Area OSPF.topo`。
- 生成方式：`scripts/ensp_topology.py` 直接解析该文件。

该拓扑是软件自带示例，不是本仓库原创实验。本次没有重新启动其中设备，也没有重新验证 OSPF 邻居或路由连通性。自己的实验与测试记录应依据 `docs/LAB_GUIDE.md` 单独完成。
